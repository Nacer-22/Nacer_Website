# Nacer_Website

الموقع الرئيسي لهوية **HAX_NON_ROOT** — Nacer_22.

## المحتويات
- `index.html`: واجهة عربية متجاوبة.
- `assets/style.css`: تصميم أسود وأحمر.
- `assets/config.js`: الروابط التي ستتم إضافتها لاحقاً.
- `assets/app.js`: القائمة المتجاوبة وتفعيل روابط البطاقات.

## التشغيل والنشر
يمكن فتح `index.html` مباشرة للمعاينة. للنشر المجاني عبر GitHub Pages:
1. افتح Settings داخل هذا المستودع.
2. اختر Pages.
3. اختر Deploy from a branch ثم الفرع `main` والمجلد `/(root)`.
4. احفظ الإعداد وانتظر اكتمال نشر Pages.

## إضافة الروابط لاحقاً
عدّل القيم داخل `assets/config.js`:
- `reseller`: رابط لوحة الموزعين.
- `password`: رابط إدارة كلمة المرور.
- `config`: رابط مستودع/صفحة الإعدادات.
- `telegram`: رابط التواصل.

ضع روابط HTTPS فقط. لا تضف كلمات مرور أو رموز وصول إلى هذا الملف؛ المستودع عام.
