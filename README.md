# Nacer_Website

واجهة **HAX_NON_ROOT** المستوحاة من تصميم لوحة الموزّعين المرجعية، بألوان الأسود والأحمر.

## الملفات
- `index.html`: واجهة تسجيل الدخول ولوحتي المدير والموزّع.
- `assets/app.js`: منطق الواجهة واتصال API.
- `assets/config.js`: عنوان API لخادم HAX_RESELLER.
- `assets/style.css`: ملف التصميم السابق، غير مستدعى من الصفحة الحالية.

## ربط الخادم
الموقع واجهة ثابتة؛ GitHub Pages لا يشغّل خادم Express. لتفعيل تسجيل الدخول وإنشاء المفاتيح:

1. انشر مشروع `Nacer-22/HAX_RESELLER` على Railway أو Render.
2. ضع عنوان الخدمة (Origin فقط) في `API_BASE_URL` داخل `assets/config.js`.
3. في متغير `ALLOWED_ORIGINS` لخدمة HAX_RESELLER، أضف أصل GitHub Pages:
   `https://nacer-22.github.io`
4. أعد نشر الواجهة بعد حفظ الإعدادات.

عند تقديم الواجهة والخادم من النطاق نفسه، اترك `API_BASE_URL` فارغاً.

## الأمان
لا تضع كلمات مرور المدير أو رموز JWT أو مفاتيح سرية في هذا المستودع العام. بيانات دخول المدير تُضبط كمتغيرات بيئة داخل خدمة HAX_RESELLER.
